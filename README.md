# Olivia Lin — Portfolio

Personal portfolio and résumé site for [Oliviaiii](https://github.com/Oliviaiii), built as a dependency-free static site for GitHub Pages.

## Local preview

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Publish with GitHub Pages

Create the public repository `Oliviaiii/oliviaiii.github.io`, push this folder to the `main` branch, then set **Settings → Pages → Deploy from a branch → main / root**.

## Files

- `index.html` — content and page structure
- `styles.css` — responsive visual system
- `script.js` — language switcher and lightweight motion
- `林芷筠中文履歷.pdf` / `林芷筠英文履歷.pdf` — downloadable résumés
